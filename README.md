# 苹果乐 Windows桌宠

**二创桌宠 / 开发中**

基于使用者提供的玩偶与角色参考素材制作的Windows桌宠。**人形立绘和人物动画尚未完成**；仓库用于持续修改与公开记录，当前人物动作含AI辅助重绘、近似和未精修之处，不将其描述成官方动画或完成品。

保留玩偶、形态切换、点击/拖动、自动走动及配置。没有自主玩《明日方舟》的功能。

## 构建与检查

需要Windows x64与.NET 8或更新SDK。运行build.ps1会测试并发布到app；完整构建可能下载.NET运行时。仅检查逻辑可运行：

```powershell
dotnet run --project tests/Applele.Checks -c Release
```

程序启动及操作说明见[实现记录](docs/implementation-notes.md)。旧实现记录中的“通过检查”是当时的特定检查范围，不代表人形美术已完成。app、bin、obj和诊断截图不纳入源码仓库。
